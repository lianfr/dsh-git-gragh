# dsh-git-graph

DSH 里的 Git 面板：提交图、变更、提交都在右侧栏完成，不用开终端。

## 能做什么

**提交图** —— 提交按时间从新到旧排列，分叉和合并画成连线。stash 和未提交的改动各占单独一行。默认只看当前分支，点「全览」看全部。

**变更** —— 合并冲突、已暂存、更改、未跟踪分四组列出。每一项都能暂存、取消暂存、撤销，鼠标移上去能看到增删行数；也可以整组暂存或整组撤销。

**提交** —— 写信息、点提交，`⌘/Ctrl + Enter` 直接提交，可以勾「修补上一次提交」。

**详情** —— 点一行展开抽屉：提交信息、作者、日期、父提交、文件列表、逐行 diff。抽屉插在那一行下面并把后面的行推下去，不遮挡内容。

**操作** —— 右键提交：复制哈希、检出到此提交、在此新建分支或标签、拣选、还原、合并到当前分支、变基、重置。

**同步与远程** —— 获取、拉取、推送；没有上游时按钮显示为「发布」，等同于 `git push -u`。远程仓库可以增删改，stash 可以保存、应用、丢弃。

## 怎么读这张图

越靠左越接近主干，往右依次是分出去的分支。一个分支从头到尾占同一列，不会因为提交穿插换位置——眼睛顺着一条线往下看不会断开，哪段属于哪个分支一眼能分清。

## 打开方式

面板挂在右侧栏，点「开始」页的 Git 卡片打开。

装了 [dsh-better-sidebar](https://www.npmjs.com/package/dsh-better-sidebar) 时它也能以标签页形式出现；没有它插件照样能用。

## 设置

插件详情页里有四项：

- **自动刷新间隔** —— 后台检查仓库变化的频率，可以关掉。
- **每页条数** —— 提交图一次拉多少条，翻到底自动加载下一页。
- **显示未提交的更改** —— 关掉后提交图最上面不画那一行。
- **撤销前确认** —— 撤销更改、重置历史这类不可撤销的操作，执行前先问一次。

界面跟随宿主语言，中英双语。

## 安装

```bash
dsh plugin install /path/to/dsh-git-graph
```
