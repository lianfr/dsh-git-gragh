# dsh-git-graph

简体中文 | [English](README_EN.md)

DSH 里的 Git 面板：提交图、变更、提交都在右侧栏完成，不用开终端。

## 它解决什么

- **历史不该只是列表** —— 分叉和合并画成连线，一个分支自始至终占同一列，顺着一条线往下看不会断。
- **提交细节要能就近看** —— 点一行就在下面展开：提交信息、作者、日期、父提交、文件列表、逐行 diff。抽屉把后面的行推下去，不遮挡内容。
- **变更与提交在同一处** —— 四组变更分开列出，逐项或整组暂存、撤销，写完成信息直接提交。
- **常用操作不必回终端** —— 检出、新建分支或标签、拣选、还原、合并、变基、重置、获取/拉取/推送、远程增删改、stash 保存与应用。

## 挂在哪里

| 宿主 | 条件 | 你得到什么 |
|---|---|---|
| **DSH 原生右侧栏** | 默认 | 右侧栏「开始」页里的 Git 卡片，点开就是面板 |
| **[dsh-better-sidebar](https://www.npmjs.com/package/dsh-better-sidebar)** | 装了它 | 侧边栏里的 Git 标签页 |

装了 better-sidebar 时以它为准，避免出现两个重复入口；没装也能用。

## 功能一览

| 区域 | 能力 |
|---|---|
| 提交图 | 新的在上、旧的在下，分叉与合并画成连线；stash 和未提交的改动各占一行；可切换全览与聚焦当前分支；翻到底自动加载下一页 |
| 提交详情 | 抽屉里显示提交信息、作者、日期、父提交、文件列表与逐行 diff |
| 提交右键 | 复制哈希、检出到此提交、在此新建分支或标签、拣选、还原、合并到当前分支、变基、重置 |
| 变更 | 合并冲突 / 已暂存 / 更改 / 未跟踪 四组；逐项暂存、取消暂存、撤销；悬停显示增删行数；也可整组操作 |
| 提交框 | 多行提交信息、`⌘/Ctrl + Enter` 直接提交、修补上一次提交 |
| 同步 | 获取全部远程更新、拉取、推送；没有上游时按钮显示为「发布」，等同于 `git push -u` |
| 远程与存储 | 远程仓库的增删改；stash 保存、应用、丢弃 |
| 其他 | 变更列表的树形与平铺两种视图；查看 Git 命令输出；在终端打开仓库 |

## 设置

插件详情页里有四项：自动刷新间隔、每页条数、是否显示未提交那一行、撤销前是否确认。

界面跟随宿主语言，中英双语。

## 安装

```sh
dsh plugin install /path/to/dsh-git-graph
```
